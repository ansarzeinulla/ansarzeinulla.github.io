Things I built and shipped

Faster ternary inference for llama.cpp — C++, ARM i8mm

Wrote an 8×8 blocked matrix-multiply kernel for the TQ2_0 ternary format using ARM matrix instructions, replacing the scalar path.

  • +79% prompt-processing throughput on an Apple M2 Pro (73 → 131 tokens/s).
  • Found and reported a 13% regression against Accelerate BLAS in my own patch rather than hiding it.

Open pull request to llama.cpp, a project with 90k+ stars.

126-billion-row data store with constant-time lookup — C++, Python, ZSTD

Computed and published an exact 125,698,242,527-position database, compressed to 8.96 GB and served so any single record can be read over an HTTP range request — no download, no server.

  • Combinatorial indexing instead of a database: 16 bytes per entry, O(1) lookup.
  • Public dataset with 88 downloads and a live browser demo.
